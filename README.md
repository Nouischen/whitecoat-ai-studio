## 快速開始

安裝並登入其中一個桌面AI程式 → 在「文件」準備並選定「我的AI工作室」資料夾 → 貼第一天的準備指令 → AI下載固定範本、解壓縮並核對 → 開始訪談。

已經有工作室的人沿用原資料夾，AI只補缺件。手動下載解壓縮保留為工具受限時的備援。

下載包只包含文字範本和說明，沒有安裝程式，不需 Git、Python、Node.js 或 API 金鑰。下載公開範本不需要 GitHub 帳號。請不要點 Fork、不要把填完的個人資料提交到這個公開儲存庫。

## 工作室結構

```text
我的AI工作室/
├─ 開始這裡.md
├─ 課程規則.md
├─ 認識我.md
├─ 課程進度.md
├─ 風格參考/
├─ 專業資料/
├─ 工作模板/
└─ 作品/
```

後續課程沿用這個工作室。檔名、存放位置、核准與讀回步驟固定；個人事實、風格與作品依本人而不同。固定範本能減少結構差異，不保證不同模型寫出相同句子，也不代表模型永久學會。

來源與版本：[官方平台說明](docs/platform-sources.md)。教材以 2026-10-31 查得的介面說明編寫；實測範圍與限制列在版本發布說明。
