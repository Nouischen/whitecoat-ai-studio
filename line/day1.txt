第一天・訊息 1｜下載與選資料夾

大家好，我是陳醫師

這三天先做一件之後每次用 AI 都用得上的事：讓它認識你的工作，也看看你平常怎麼寫東西

第 1 天：訪談、修正、存檔
第 2 天：放自己的文章，找出你的寫法
第 3 天：試寫、改一句，再開新對話確認

每天先預留 20～30 分鐘，安裝與登入另計。Codex、Claude Code 選一個就好，需要一台電腦；只有手機可先準備答案與文章

我們整個月都用同一個「我的AI工作室」。請先下載固定範本：
https://github.com/Nouischen/whitecoat-ai-studio/releases/download/v1.0.0/my-ai-studio-v1.0.0.zip

Windows：下載後按右鍵 → 全部解壓縮
Mac：雙擊 ZIP 解壓縮

把裡面的「我的AI工作室」整個資料夾複製到電腦的「文件」。請確認打開它就看得到「開始這裡.md」，不要直接在 ZIP 裡操作。若文件裡已有同名資料夾，先不要取代；請先開啟 https://github.com/Nouischen/whitecoat-ai-studio/blob/main/INSTALL.md 的「已有同名工作室」，只補缺件，保留舊內容

教材與卡關說明：
https://github.com/Nouischen/whitecoat-ai-studio

這堂課要用能讀寫本機資料夾的桌面功能；一般瀏覽器裡的 ChatGPT／Claude 聊天不能照這份流程存進你的電腦

接著選一條操作路線：

【Codex】
安裝並登入官方桌面 App，切到 Codex。建立本機專案並選取剛才的「我的AI工作室」。如果找不到資料夾設定，可從專案選單找 Edit project → Add folder；這個專案先只放這個資料夾
開新對話時選 Work in → This computer；使用目前資料夾
官方安裝與起步：https://learn.chatgpt.com/docs/quickstart

【Claude Code】
安裝並登入 Claude 桌面 App → Code 分頁 → 輸入框下方選 Local → 旁邊的資料夾選單 Open folder… → 選「我的AI工作室」
需要帳號可使用 Code。輸入框下方若顯示 Plan，點模式選單改成 Manual（舊版叫 Ask permissions），讓它提出修改後由你確認。若出現升級或登入提示，先依官方說明處理
官方安裝與起步：https://code.claude.com/docs/en/desktop-quickstart

介面名稱可能稍有不同。重點是選到這台電腦上的工作室資料夾。工具要求確認變更時，確認路徑在「我的AI工作室」裡再同意。選錯資料夾就回到上述資料夾選單重選；不要靠對話裡打路徑來換位置

練習用願意交給 AI 的工作資訊即可，不放密碼或可辨識的病人資料；本機檔案被 AI 讀取後，仍可能送到雲端處理

等一下標成「貼給 AI」的內容，複製到你選的工具裡。群組只回報進度和一句改過的話，不用交整份個人檔案

第一天・訊息 2｜訪談指令

【貼給 AI｜第一天訪談】
先顯示目前工作資料夾完整路徑，確認我選的是「我的AI工作室」，只列出第一層項目。實際讀取「開始這裡.md」「課程規則.md」「認識我.md」「課程進度.md」。找不到、無法讀取或位置不對，先停並說明，不要假裝已讀取，也不要自行另建工作室。

這次依課程規則，只在本工作室工作。請用繁體中文訪談我，一次只問一題，等我回答再繼續，約 6～8 題，已回答的不用重問。

了解我的角色、主要溝通對象、最想請 AI 幫忙的工作、做事在意什麼、一個具體例子，以及喜歡和不喜歡的寫法。依回答調整問題；每個偏好也問清楚適用場合。

我可以說「跳過」或「先停，整理」。不要替我補學經歷、年資、院所、資格。

結束後分成「我明確提供的事實」「我表達的偏好」「未提供或待確認」，讓我逐條修正。推測要標示，先不要存檔。
【指令結束】

AI 應該先列出路徑和讀過的檔案，再問第一題。最後的整理請自己讀一遍，不對就說「第幾條改成……」，請它顯示修正版

例如它寫「資深家醫科醫師」，你沒提供年資，就說：「我沒有說年資，把資深拿掉」

第一天・訊息 3｜存檔與回報

整理看過、修過、認可了，再貼這段：

【貼給 AI｜確認存檔】
確認，請依課程規則，將我修正並認可的事實和偏好合併進「認識我.md」的對應段落。未提供、待確認和你的推測留在對話，不寫進正式個人資料。

修改前重新讀檔並備份，只改這次核准內容，保留其他內容；有矛盾先問。不要改固定檔名或另造正本。

完成後實際重新讀取，顯示路徑、存入的事實與偏好，讓我核對。「課程進度.md」的 01-A 記成「AI 已讀回，本人待核對」；等我說已打開檔案且核對正確，再記本人核對完成。寫入失敗就明說尚未存檔。
【指令結束】

現在自己打開「文件 → 我的AI工作室 → 認識我.md」，看一項事實和一項偏好有沒有存對，再回 AI：「我已打開檔案，核對正確，請更新進度」

.md 就是文字檔。雙擊沒開對程式，可按右鍵選記事本或文字編輯
