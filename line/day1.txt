第一天・訊息 1｜先準備電腦裡的工作室

大家好，我是陳醫師

這三天，我們要讓 AI 認識你的工作，也看看你平常怎麼寫東西
第1天：訪談、修正、存成電腦裡的檔案
第2天：放自己的文章，找出你的寫法
第3天：試寫、改一句，再開新對話確認

先不用分清楚所有 AI 名詞，照下面的按鈕一步一步做就好

你平常可能在瀏覽器打開 ChatGPT 或 Claude，直接跟它聊天。這次要多做一步：讓 AI 讀寫你電腦裡的一個資料夾。單純把資料夾路徑貼在網頁聊天框，不代表它已經連上你的電腦

我們會用桌面程式裡的 Codex 或 Claude Code 功能。選一條路線即可，兩個不用都學
「本機」在這裡是指檔案存到自己的電腦；AI 仍需連網，也可能將讀到的內容送到雲端處理

請準備一台 Windows 或 Mac 電腦。每天先預留20～30分鐘，第一次安裝登入另計。只有手機的人先準備答案與文章，回電腦再完成存檔

【今天誰做什麼】
你負責打開桌面程式、登入自己的帳號，並選好一個課程專用資料夾。下載教材、解壓縮、放好檔案和檢查內容，都交給AI

先在電腦的「文件」裡準備一個叫「我的AI工作室」的空白資料夾，當作AI的工作範圍
Windows：開檔案總管 →「文件」→ 右鍵空白處 →「新增」→「資料夾」，命名為「我的AI工作室」
Mac：開Finder →「文件」→ 上方「檔案」選單 →「新增檔案夾」，命名為「我的AI工作室」
若選資料夾視窗已有「新增資料夾」按鈕，也可以在那裡建立

原本已有同名工作室的人直接選原本那個，不用清空、另建或重新下載；等一下的AI指令會保留舊檔，只補缺件

接下來：
平常用ChatGPT的人，看下一則「A路線」
平常用Claude，而且帳號能用Code的人，看「B路線」
兩個都有，任選一條。Claude Code需要支援此功能的付費方案；已有可用的Codex，不必為這課多訂一套

練習用願意提供給AI的工作資訊，不放密碼或可辨識病人資料。群組只回報進度和一句改過的話，不用交整份個人檔案

第一天・訊息 2A｜用 ChatGPT 的人，從這裡進 Codex

【A路線：用ChatGPT的人】
這一則只做「打開對的程式、選到對的資料夾」，先不用訪談

1. 在電腦開官方起步頁：
https://learn.chatgpt.com/docs/quickstart
找到「Setup／設定」區，選「Desktop／桌面」，按「Download ChatGPT」，下載適合Windows或Mac的版本，打開下載檔並依畫面安裝
已安裝最新版桌面程式的人可以跳過安裝

2. 安裝後，從Windows開始選單，或Mac的「應用程式」打開ChatGPT程式，用自己的ChatGPT帳號登入。這裡要開的是電腦程式，不是瀏覽器裡的聊天網頁
沒有帳號時依登入畫面註冊；本課不用API金鑰

3. 在程式左側上方找到「ChatGPT」的下拉選單，點開後選「Codex」。如果目前已顯示Codex，就不用再切
Codex是我們這次用來操作電腦資料夾的功能，看到這個名字即可，不用先學寫程式

4. 在左側找「專案／Projects」，點旁邊的「＋／新增專案」。建立一個叫「我的AI工作室」的專案
若直接跳出選資料夾視窗，就選「文件 → 我的AI工作室」

5. 在剛建立的專案名稱旁開「…」選單 →「編輯專案／Edit project」→「新增資料夾／Add folder」→ 選「文件 → 我的AI工作室」
若剛才已加過，而且清單只有這個資料夾，就不用再加。本課這個專案只放這一個資料夾
注意：只在ChatGPT網頁建立一個同名「專案」，還不等於選到了電腦資料夾；這一步要真的看見資料夾選擇視窗

6. 從這個專案開「新對話／New chat」。在新對話畫面找「Work in」，選「This computer／這台電腦」。若有Cloud或Worktree選項，這課先不選

7. 看輸入框下方的權限選單，選「Ask for approval／要求核准」。這個模式可以讀寫目前工作室；若顯示Read-only／唯讀，也在這個選單改選Ask for approval。出現存取或變更要求時，先核對檔案路徑在「我的AI工作室」裡，再同意。這課不需要選Full access／完整存取

8. 若畫面顯示「Plan／規劃模式」，先在空白輸入框輸入 /plan，從出現的指令清單選它，關閉規劃模式後再繼續；原本沒開Plan就不用切換

權限選項反灰、看不到指令清單，或關閉後仍停在Plan時，先回群組「A路線第7或8步＋畫面文字」。不要用提示詞硬闖唯讀，也不要更改全域設定

做到這裡，再貼下一則「請AI準備工作室」指令
看不到Codex、資料夾選項，或帳號顯示不能使用時，先回群組「A路線第幾步＋畫面上的文字」，不用猜按鈕，也不用先更改整台電腦的權限

第一天・訊息 2B｜用 Claude 的人，從這裡進 Code

【B路線：用Claude的人】
如果你已經走A路線，這則可以跳過

1. 在電腦開官方起步頁：
https://code.claude.com/docs/en/desktop-quickstart
Windows按「Download for Windows」；Mac按「Download for macOS」。打開下載檔，依畫面安裝Claude桌面程式
已裝好的人直接開程式，不必另裝另一個叫Claude Code的程式

2. 從Windows開始選單，或Mac的「應用程式」打開Claude，用自己的帳號登入。不是在瀏覽器裡繼續原本那個Claude聊天頁
Claude Code需要支援它的付費方案。若出現升級提示，先確認自己的方案；已有可用Codex的人可改走A路線，不必為本課多訂一套

3. 在程式左側欄上方點「Code」。如果只看到圖示，把滑鼠停在圖示上，看名稱再點
進到Code分頁，才是這次要用的Claude Code功能；一般Chat聊天分頁先不用

4. 看輸入文字的框下方。點第一個「環境」選單，選「Local」那一組最上面的本機選項
Local在這裡就是用這台電腦的資料夾。Cloud、SSH或WSL先不用選

5. 點旁邊的資料夾選單 →「Open folder…／開啟資料夾」→ 選「文件 → 我的AI工作室」
若你是舊版介面，環境與資料夾選單可能在輸入框上方；位置不同時，依這個官方說明頁的舊版畫面確認，不要在一般聊天框硬貼電腦路徑

6. 看輸入框下方的模式。若是「Plan」，點它改成「Manual」，舊版可能叫「Ask permissions」
Plan只會規劃；Manual可以提出檔案修改，等你確認後執行。看到確認時，先看路徑確實在「我的AI工作室」裡，再同意

做到這裡，再貼下一則「請AI準備工作室」指令
不需要另裝Node.js、不需要開終端機，也不用API金鑰。看不到Code或卡住時，回群組「B路線第幾步＋畫面上的文字」即可

第一天・訊息 3｜請 AI 準備工作室

現在把下面「貼給AI」到「指令結束」中間的文字，複製到剛才選好資料夾的Codex或Claude Code輸入框，送出
不要貼回LINE，也不要貼進一般網頁聊天框

【貼給 AI｜準備工作室】
請先用實際工具確認目前選定資料夾的完整路徑；它應該是我在「文件」裡的「我的AI工作室」。若不是，先停並教我選對位置。

請讀取這份課程安裝說明，依照說明幫我下載固定範本、解壓縮、放好檔案並讀回核對：
https://raw.githubusercontent.com/Nouischen/whitecoat-ai-studio/v1.0.1/BOOTSTRAP.md

只在這個工作室新增缺少的教材檔案；已有檔案一律保留，不覆蓋、不刪除，也不要在裡面再套一層「我的AI工作室」。

下載或檔案存取需要平台核准時，請提出核准要求，讓我按畫面確認。工具、網址或權限真的無法使用時，明說卡在哪一步，不要假裝完成或自行編造範本。

完成後，列出實際新增、保留的檔案，從「課程規則.md」引用一條原文，並讀出「課程進度.md」的01-A目前狀態。先不要開始訪談。
【指令結束】

接下來由AI下載、解壓縮並檢查。若跳出網路或檔案存取確認，先看它是否正在下載本課教材、操作「我的AI工作室」，再同意

AI回報完成後，自己打開「文件 → 我的AI工作室」，核對：
□ 直接看得到開始這裡.md、課程規則.md、認識我.md、課程進度.md
□ 有風格參考、專業資料、工作模板、作品四個資料夾
□ AI引用的規則真的在課程規則.md裡
□ 新工作室的01-A是未開始；舊工作室的資料和進度仍保留

.md是文字檔，可用記事本或文字編輯開啟。不應出現「我的AI工作室裡面又有一個我的AI工作室」

確認成功後再做下一則訪談。如果AI只是教你手動下載，請回它：「請使用你的工具實際完成下載與整理；若工具受限，告訴我具體卡在哪一步」

第一天・訊息 4｜訪談指令

【貼給 AI｜第一天訪談】
先顯示目前工作資料夾完整路徑，確認我選的是「我的AI工作室」，只列出第一層項目。實際讀取「開始這裡.md」「課程規則.md」「認識我.md」「課程進度.md」。找不到、無法讀取或位置不對，先停並說明，不要假裝已讀取，也不要自行另建工作室。

這次依課程規則，只在本工作室工作。請用繁體中文訪談我，一次只問一題，等我回答再繼續，約 6～8 題，已回答的不用重問。

了解我的角色、主要溝通對象、最想請 AI 幫忙的工作、做事在意什麼、一個具體例子，以及喜歡和不喜歡的寫法。依回答調整問題；每個偏好也問清楚適用場合。

我可以說「跳過」或「先停，整理」。不要替我補學經歷、年資、院所、資格。

結束後分成「我明確提供的事實」「我表達的偏好」「未提供或待確認」，讓我逐條修正。推測要標示，先不要存檔。
【指令結束】

AI 應該先列出路徑和讀過的檔案，再問第一題。最後的整理請自己讀一遍，不對就說「第幾條改成……」，請它顯示修正版

例如它寫「資深家醫科醫師」，你沒提供年資，就說：「我沒有說年資，把資深拿掉」

第一天・訊息 5｜存檔與回報

整理看過、修過、認可了，再貼這段：

【貼給 AI｜確認存檔】
確認，請依課程規則，將我修正並認可的事實和偏好合併進「認識我.md」的對應段落。未提供、待確認和你的推測留在對話，不寫進正式個人資料。

修改前重新讀檔並備份，只改這次核准內容，保留其他內容；有矛盾先問。不要改固定檔名或另造正本。

完成後實際重新讀取，顯示路徑、存入的事實與偏好，讓我核對。「課程進度.md」的 01-A 記成「AI 已讀回，本人待核對」；等我說已打開檔案且核對正確，再記本人核對完成。寫入失敗就明說尚未存檔。
【指令結束】

現在自己打開「文件 → 我的AI工作室 → 認識我.md」，看一項事實和一項偏好有沒有存對，再回 AI：「我已打開檔案，核對正確，請更新進度」

.md 就是文字檔。雙擊沒開對程式，可按右鍵選記事本或文字編輯
