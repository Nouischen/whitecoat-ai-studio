# 第二課｜讓 AI 幫你找到網頁上的入口

```text
你有沒有開過一個網站，知道要找什麼，卻不知道該點哪裡？今天用電腦版 Chrome 試一次，請 AI 直接幫你點到那一頁。

① 選平常用的那一個，點官方連結 →「加到 Chrome」→「新增擴充功能」。
Claude：https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn
ChatGPT：https://chromewebstore.google.com/detail/chatgpt/hehggadaopoacecdllhhajmbjkdcmajg

② 在 Chrome 開這個英文網站：https://developers.openai.com/api/docs
留在這個分頁，點右上角拼圖，再點剛裝的 Claude 或 ChatGPT。看到對話欄後，依畫面登入。用 ChatGPT 的人也可以到 chatgpt.com，打 @Chrome 或按「＋」選剛才的分頁。

③ 把這句貼給 AI：
「請操作我開著的分頁，幫我找到『如何建立 API 金鑰』的說明。點進去，捲到那一段就停，把畫面留給我看。不要建立金鑰。」

看到 Quickstart 頁面的「Create and export an API key」，就找到了。今天練到這裡。如果 AI 只回答文字，提醒它「請直接操作我選的分頁」。帳號無法操作的同學跟著看示範即可。

想想看，下次你會用在哪裡？例如找醫學會的年會報名表，或查迪士尼郵輪哪天有船。幫自己留一句：「下次我想請 AI 到＿＿網站，幫我找到＿＿，停在＿＿。」
```
