# 第五課｜在工作室加上文獻查核方法

這份給正在學員電腦上操作的 Codex 或 Claude Code 讀。學員已要求把第五課方法放進目前工作室，請實際下載、安裝、讀回。全程只操作學員選定的工作室。課程資料放在學員自己的電腦，查研究只傳一般醫學關鍵字、公開 DOI 或 PMID。

## 下載本課的四個檔案

先確認這裡是學員在第一課建立的工作室。若是學員的家目錄、下載區或教材儲存庫，先請學員選回原工作室。「工作模板」資料夾不存在時可以建立。檢查目標與父目錄確實在工作室內，遇到符號連結、junction、檔案和資料夾型別衝突，就停在該處說明原因。

版本固定為 `lesson-05-v1.0.0`。下列每一個檔案都從這個前綴加上檔名下載：

https://raw.githubusercontent.com/Nouischen/whitecoat-ai-studio/lesson-05-v1.0.0/lessons/05-literature/

把檔案先下載至新的暫存目錄。請取網址的原始回應 bytes，保留編碼和換行，勿把網頁閱讀工具的摘要再寫成檔。用 Windows 的 Get-FileHash、macOS 的 shasum -a 256 或同等本機工具逐檔核對下表。四筆全部一致再放進工作室。平台若要求網路或檔案存取，請使用正常授權畫面。本課安裝只需下載檔案及加上文字入口，無須執行下載的程式。

## 安裝與重複執行

1. 目的地是工作室的 `工作模板/文獻版/`。四個檔案都放這裡。先檢查四筆目的地，缺件才新增，已存在而內容完全一樣的直接沿用。若同名檔內容不同，先說是哪一個檔有差異，保留現有內容；不要靜默替換或宣稱已安裝新版。
2. 讓兩個平台在新對話裡都找得到。工作室根目錄的 `AGENTS.md` 和 `CLAUDE.md` 各放一行下面的文字。沒有檔案才新建；有檔案時先讀回並保留原來的內容與編碼，在末尾獨立一行追加。修改現有檔前留一份本機備份，不覆寫以前備份。若這一行已存在，略過；若有同名第五課提示卻指向不同版本或路徑，先報告衝突。不要更動整台電腦或其他專案的規則。

【白袍 AI 第五課 v1.0.0】在這個工作室收到「幫這篇做文獻版」或同義要求時，先讀「工作模板/文獻版/WORKFLOW.md」，依步驟實際查證並另存 Word。

3. 從磁碟重新打開兩份入口檔與四份教材。指引各出現一次，四份教材的 SHA-256 再逐一比對；只在全部一致時回報已裝好。重跑同一版時應沿用既有檔案，不多加一份或多貼一行。下載失敗或校驗不符，報告實際缺哪個檔，保留原工作室。
4. 告訴學員在同一個工作室開新對話、輸入「幫這篇做文獻版」。製作 Word 和上網查證時依 WORKFLOW.md 的步驟，使用學員環境提供的工具；Python 小幫手是選用項目，只在已裝 Python 3.9+ 時使用。安裝完不需要把文章送回 GitHub。
