# 衛教影片上架單

把影片重點交給工作室，取回標題、說明與填表指令。需要從網頁找背景資料時，可直接貼公開網址。只有要點選頁面或輸入資料時才開擴充功能。[課堂帶做與安裝入口](LINE.md)

## 做一份上架單

把這段存起來。第一次可選下方範例 A，或在指令最後貼自己的影片重點。

```text
請把我提供的影片做成一份上架交接單。先讀「我的AI工作室」裡我已確認、適合公開的個人資料與口吻，只用與這支片有關的部分。

我會給影片檔名、觀眾和重點或逐字稿。給了範例代號就用本頁對應資料。新素材請沿用我的代號；沒指定時先問我這次要用的唯一代號。若我附公開文章，直接讀網址作為補充；只看到部分就告訴我。依據我提供的影片內容寫一個標題、一小段可放進 YouTube 說明欄的文字。不要寫進素材沒提的療效、經歷或聯絡資訊。只有重點文字就依文字起草，別說你看過影片。不確定的事列給我確認。

先讓我看標題和說明。採用我改過的版本後，產生一筆七欄資料，每格一行內寫完，固定欄序：
素材代號｜影片檔名｜觀眾｜標題｜影片說明｜待醫師確認｜狀態
狀態預設「待確認」。把跟這支片有關的來源和七欄存進「作品/」，檔名包含素材代號，同名用下一個空號碼。把通用做法存為「工作模板/衛教影片上架單.md」；模板內附七欄順序、「填入表格」指令和兩張課堂素材卡的固定來源 https://raw.githubusercontent.com/Nouischen/whitecoat-ai-studio/v1.2.0/lessons/02-handoff/WORKFLOW.md ，讓新對話也能讀到。已有自己的同名模板就保留並沿用，缺上述內容就提供本次補充給我。讀回這次實際存的檔名和標題。沒有本機檔案工具就給我可另存的文字。

最後產生一則可以整段貼給瀏覽器 AI 的指令：將本頁「填入表格」指令和本次七欄資料放在同一個文字框，欄與欄之間用真正的 Tab 分開。只帶可填進表內的文字，其他工作室資料留在原處。
```

**兩筆練習素材**（均為虛構文字，沒有附影片檔）

| 代號 | 影片檔名 | 給誰看 | 影片實際要講的兩件事 |
|---|---|---|---|
| A／V01 | 回診怎麼準備.mp4 | 初次回診的民眾 | 先寫下想問的兩個問題。把手邊的檢查報告放在一起。 |
| B／V02 | 講座提問.mp4 | 報名線上講座的民眾 | 課前在報名信找到提問入口。一次留一個問題。 |

## 填入表格

第一次，在 Chrome 開啟[自己的空白試算表](https://sheets.new)，命名為「我的影片上架單」。已有這張表就直接開它。在 Chrome 的 Claude 側欄，或在已選取目標 Chrome 分頁的 ChatGPT 對話，貼上含本次資料的完整指令。

```text
請操作我選取的「我的影片上架單」Google 試算表分頁。確認試算表名稱及所在工作表。在全新的空白表，先從 A1 到 G1 加入這七個表頭：素材代號、影片檔名、觀眾、標題、影片說明、待醫師確認、狀態。已有表頭就核對名稱和順序；不相符或看不清楚就停下告訴我。

先查 A 欄這次的素材代號。已存在就告訴我在哪一列，不改舊值，也不新增。若是新代號，在資料末端之後、A 到 G 全空白的一列填入以下七格。等表格儲存，再從表上讀回，核對代號、檔名、標題、說明及其他三格，告訴我填在哪一列。無法確定有沒有寫進去時先停，讓我看表後再處理。
本次七欄資料：
〔工作室把這一筆的實際七格資料放在這裡〕
```

**完成範例**。措辭可以改，代號、檔名與素材事實要對。下方是已填好的練習答案。工具受限時，可把範例逐列手動貼入試算表。

```tsv
素材代號	影片檔名	觀眾	標題	影片說明	待醫師確認	狀態
V01	回診怎麼準備.mp4	初次回診的民眾	回診前，先寫下兩個問題	先寫下這次回診最想問的兩個問題，再把手邊的檢查報告放在一起。這支影片帶你準備這兩件事。	練習素材；正式使用前核對影片內容。	待確認
V02	講座提問.mp4	報名線上講座的民眾	想在講座提問？先從報名信找入口	課前先在報名信裡找到提問入口。留言時，一次留一個問題。	練習素材；正式使用前確認報名信裡的入口。	待確認
```

## 同一個擴充功能，換四件事試試

**填講師資料表。** 開主辦單位的表單，在旁邊的 AI 對話貼下面這段，再接上你已確認要交給主辦方的資料。

> 請把我附的姓名、服務單位、講題及簡介填進眼前對應欄位。缺的留白，把要問我的欄位列出來。填好後停在送出前，讓我看一次。

**在全英文的 API 後台找分頁。** 先登入自己要查的帳戶。

> 幫我從目前頁面點到 Usage（使用量），找出本月的日期範圍與用量單位。停在那一頁，把你點過的選單名稱告訴我，下次我就找得到。不開金鑰頁。

**查迪士尼門票。** 先開你要去的園區官方網站，補上日期、人數。

> 請從這個園區的官網點進訂票，查〔日期〕、〔人數與年齡〕能選的票種、價格與幣別。把符合條件的選項留在畫面上給我看，停在購買前。

**把自己的衛教片上傳到 YouTube。** 準備好自己有權上傳的實際影片和已核定的標題、說明。選檔後影片就會傳到 YouTube；「私人」是誰能觀看的設定。[YouTube 官方上傳步驟](https://support.google.com/youtube/answer/57407)

> 我已開好 YouTube Studio。請先跟我核對頻道、影片檔名，再點「建立 → 上傳影片」。如果你不能選本機影片，就停在「選取檔案」，等我自己選。用我附的上架單填標題、說明；兒童內容等必要選項由我決定。本次可見度選「私人」並儲存。最後到「內容」確認同一支片的標題、可見度、上傳及處理狀態。還在處理就告訴我進度。
