# 第二課｜把衛教影片交給助理上架

一堂約 20–30 分鐘，第一次安裝擴充功能的時間另計。依序貼以下三則到 LINE，每個框可以整段複製。

## 第一則｜把這支影片變成一份上架單

```text
錄完衛教影片，助理問你：「標題放什麼？說明欄怎麼寫？」今天就把這兩件事做完，放進一張下次還能用的交接表。

打開第一課用過的 Codex 或 Claude Code，選原本的「我的AI工作室」。把下面的指令整段貼給它：

請讀這份課程模板的「做一份上架單」，照那段指令實際做。如果讀不到，請告訴我，我會打開教材把該段和範例 A 貼給你。
https://raw.githubusercontent.com/Nouischen/whitecoat-ai-studio/v1.2.0/lessons/02-handoff/WORKFLOW.md
這次用範例 A。只讀我已確認、適合公開的口吻或署名資料。先做一個 YouTube 標題和一小段說明給我看。

有自己的影片，就把「這次用範例 A」換成檔名、給誰看、影片講了什麼。兩三句重點或一段逐字稿都可以。有公開衛教文章想當參考，直接貼網址，AI 讀不到再補原文。

讀一下草稿，把你平常不會講的句子改掉。覺得可以交給助理了，就回：「用這版。把這次的交接稿和下次可用的指令各自存好，給我一段可以貼到瀏覽器填表的指令，裡面帶上這次要填的內容。」

第一次加入的人，可以先開電腦上的 ChatGPT 或 Claude 對話，用範例 A 完成今天的填表。工作室還沒建好，就先把可重用指令另存成自己的文字檔。
```

## 第二則｜請 AI 動手填表

```text
在電腦版 Chrome 開 https://sheets.new ，登入自己的 Google 帳號。看到白色格子後，把左上角的試算表名稱改成「我的影片上架單」。今天讓 AI 幫忙的就是這個分頁。Google 試算表會自動儲存，請用自己的空白表。

擴充功能挑平常用的那一個：
• Claude：從官方說明的安裝連結加入 Chrome，登入後，在剛才的表格分頁點右上角拼圖 → Claude，旁邊會開一個對話欄。
https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome
• ChatGPT：依官方說明安裝 ChatGPT 的 Chrome 擴充功能。在同一個 Chrome 另開 ChatGPT 網頁，在輸入框打 @Chrome 或按「＋」，選剛才的「我的影片上架單」，依畫面允許這次操作。
https://help.openai.com/en/articles/20001277-using-the-built-in-browser-in-the-chatgpt-desktop-app

貼上工作室剛給你的「填表指令」，裡面應該看得到這支影片的檔名、標題和說明。送出後，看著 AI 把資料填進表裡。

拿範例 A 練的人，請看表格第二列。A2 是 V01，B2 是「回診怎麼準備.mp4」，D2、E2 是你剛才看過的標題和說明，G2 是「待確認」。影片還要核對，所以先留這個狀態。

工具找不到那張表，就重新選分頁。帳號目前無法操作時，請工作室給你「表頭和一列資料，用 Tab 分七格」。點空白表 A1 貼上，若已有相同表頭，先查素材代號，僅貼資料列到表尾空白列。這樣有交接單，擴充操作留待補練。
```

## 第三則｜換一支影片，再用一次

```text
回到同一個工作室，試試第二句交辦：

「用存好的『衛教影片上架單』處理範例 B，沿用剛才的七欄格式。下次我會直接給你新影片的檔名和重點。」

看過草稿後，把新的填表指令貼到剛才的瀏覽器對話，選同一張試算表。這次應該在下一列看到 V02「講座提問.mp4」，上一列的 V01 還在。再給它一次 V01，應該告訴你已經有了。用自己的影片就看自己的素材代號。

以後錄完一支片，交給助理的是實際影片檔和這一列上架資料。助理看得到要用的標題、說明，還有哪件事要請你確認。

今天回報一句就好：「我用＿＿，影片標題是＿＿，結果是 AI 填好了／我手動貼好了／卡在＿＿。」

要用同一個擴充功能填講師表單、找英文網站的 API 用量頁、查迪士尼門票，或把自己的影片傳到 YouTube，可直接複製模板最下面的示範指令：
https://github.com/Nouischen/whitecoat-ai-studio/blob/v1.2.0/lessons/02-handoff/WORKFLOW.md
```
