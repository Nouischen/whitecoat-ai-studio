# 第二課｜讓 AI 操作瀏覽器

此頁保留舊版三天練習。現行第二課請從[Chrome 找頁練習](../02-chrome/LINE.md)開始。

教材版本：1.1.0；沿用第一課資料夾格式 1。

這一課請 AI 打開文章、點連結讀內容，核對後存進原來的「我的AI工作室」。使用電腦版 Codex 或 Claude Code，選一套即可。每天預留 20～30 分鐘；首次登入或平台問題另計。

完整帶做文字放在[三天 LINE 訊息](https://github.com/Nouischen/whitecoat-ai-studio/blob/v1.1.0/lessons/02-browser/LINE.md)，每一則都能單獨複製。

## 現在從這裡開始

1. 在桌面程式選取第一課的「我的AI工作室」。不用另建工作室，第一課也不必全部做完。
2. 把下面這整段一次貼給 AI，下載與整理交給它：

> 請讀取 https://raw.githubusercontent.com/Nouischen/whitecoat-ai-studio/v1.1.0/lessons/02-browser/BOOTSTRAP.md ，依其中步驟只補齊第二課純文字教材，保留我的既有檔案。完成後讀取本工作室的「工作模板/02-瀏覽器教材/TASKS.md」，從課程進度接續；第一次就帶我做第一天。我只負責選工作室、必要的平台核准與親自核對。不要安裝開發工具、改全域設定或發布任何內容。若網址或工具不能使用，請說明卡在哪一步，不能假稱完成。

預期會看到：AI 回報工作室位置、六份教材新增或保留的結果，再用瀏覽器帶你進入共同文章。第一次參加、還沒有工作室，先照[第一課：選資料夾並準備工作室](https://github.com/Nouischen/whitecoat-ai-studio/blob/v1.0.1/line/day1.txt)，做到準備成功就能接第二課。原工作室有缺件時，請 AI 只補缺件。

## 三天各留一件成果

| 哪一天 | 要做什麼 | 留下什麼 |
|---|---|---|
| 第一天 | AI 用瀏覽器開起始頁，點進共同文章；你核對標題與兩處原文 | 作品中的共同練習資料卡 |
| 第二天 | 換你自己的文章，確認作者、用途與實讀範圍 | 風格參考中的原文、來源與核對紀錄 |
| 第三天 | 開新對話選同一工作室，找回同一張卡並核對引用 | 讀回結果，以及你對初步觀察的裁決 |

操作細節在 [TASKS.md](TASKS.md)。瀏覽器共同練習從 [線上共同練習入口](https://github.com/Nouischen/whitecoat-ai-studio/blob/v1.1.0/lessons/02-browser/START.md) 進入；AI 必須實際點其中的連結。

資料卡要保留標題、作者、日期、網址、正文、讀取範圍與核對狀態。摘要與觀察另外寫。你的文章完整保存、AI 實際讀回、你核對兩處並確認後，才把對應進度記為完成。單篇只作初步觀察，是否留作往後的風格依據由你決定。

還沒有自己的文章，可以繼續用共同文章練習。進度記「共同練習完成，本人文章待補」，不把示範算成你的作品或風格。每個人的摘要可以不同；固定教材統一的是來源、保存方式和完成標準。

## 使用哪個瀏覽器

先用桌面程式內建的瀏覽器讀公開頁。在 Codex 的輸入框打半形 @，從選單點 Browser，也可以直接要求「請用內建瀏覽器」；Claude Code 請在 Code 的本機工作室對話點右上方的地球圖示「瀏覽器／Browser」，或按 Windows 的 Ctrl＋Shift＋B、Mac 的 ⌘＋Shift＋B。介面與可用功能可能依帳戶或組織不同。

首次出現正常網站核准提示時，由你確認；不提供密碼或驗證碼給 AI。工具被組織停用時，回報主持人，不改安全設定繞過。沒有瀏覽器工具時，下載可以先做，瀏覽器練習仍未完成。

### 選修：只有自己的文章需要登入時

先由你在自己的 Chrome 登入；內建瀏覽器與 Chrome 登入狀態通常分開。確實需要時才依平台官方引導連接 Chrome：Codex 從 Settings 的 Computer Use 入口安裝官方擴充，再於對話選 @Chrome；Claude 依 Settings → Customize → Connectors → Claude in Chrome → Configure 的官方引導，並在當次對話啟用連接。若你的版本沒有這些入口，請回報畫面與卡點。

這是限定讀取你指定的自有文章的選修。不要求安裝命令列工具；不要把 Cowork 側欄當成已選好本機工作室的 Code 對話。暫時不能連接時，先用公開共同文章。

## 中斷、換工具或下載失敗

回到同一工作室，整段貼給 AI：

> 請讀取「課程規則.md」「課程進度.md」「開始這裡.md」和「工作模板/02-瀏覽器教材/TASKS.md」，確認進度記錄中的實際檔案，從未完成的一步接續。保留已完成內容，不重建工作室，不猜檔名，也不把尚未核對記成完成。

同一時間只讓一套工具修改。下載失敗的手動備援在 [教材準備說明](https://github.com/Nouischen/whitecoat-ai-studio/blob/v1.1.0/lessons/02-browser/BOOTSTRAP.md) 的「下載失敗才用的手動備援」；不需安裝 Python、Node.js 或 Git，也不需自行搬動或拼裝提示詞。

只下載或手動備妥素材，不能算 AI 瀏覽器操作成功。若只能讀部分、圖片無法辨識或遇登入牆，就記下實際範圍。回報群組時只需說哪一天、工具、已做到哪一步和卡點，不用公開個人文章或整份工作室。
