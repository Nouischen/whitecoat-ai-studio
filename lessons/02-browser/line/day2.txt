【第2課・第2天｜1／2】換成你自己的文章

今天帶走一張文章資料卡，下次要寫衛教文時，可以回來找到原文與網址。

挑一篇公開、你自己點開就看得到全文的文章，部落格、官網、公開貼文都可以，先一篇就好。
選一篇適合交給 AI 的文章，略過含可辨識病人資訊的內容。先分清楚作者：
・本人親自寫
・他人寫或代筆（就算掛你的名字）
代筆的可以存，但之後不拿來當你的語氣。
沒有文章：今天沿用共同文章練，進度記「本人文章待補」，不算本人項目完成。

沿用共同文章的人，直接回 AI：「請讀「工作模板/02-瀏覽器教材/TASKS.md」，沿昨天的共同卡練習；02-B 記本人文章待補。我今天不用另存一篇。」接著跳到今天的群組回報。

有新文章的人回同一個工作室的對話，瀏覽器保持開著（Codex 記得 @ 選 Browser）。把中括號換成你的資料再貼：

【貼給AI】
請讀「工作模板/02-瀏覽器教材/TASKS.md」的第二天說明與它指定的資料卡範本，用瀏覽器讀這篇文章：
網址：［貼完整網址］
作者：［本人親寫／他人或代筆，寫是誰］
用途：［例如診所官網衛教，寫給病人］
原文照實保留，摘要另外放；只讀到一部分就標「部分」，不要補寫。頁面沒寫作者或日期就寫「未標」。先列標題、正文第一句、最後一句和沒讀到的地方；只讀到片段就標「片段末句」。等我核對再存。只讀這一篇，不發文、不傳訊。
【指令結束】

應該看到：AI貼出標題和首尾句，並說全文或部分。
要登入才看得到：先換一篇公開文章，或看今天最後的選修訊息。

========== 下一則訊息 ==========

【第2課・第2天｜2／2】你核對兩處，才存檔

自己打開原文，把首句和末句與 AI 列的兩句逐字比對。都對就貼：

【貼給AI】
我已核對［寫你比的兩處］，正確。請依 TASKS.md 保存。本人親寫放「風格參考/02-網頁文章-01.md」，他人或代筆放「作品/02-他人文章練習-01.md」並記本人文章待補。同一篇重送用原卡，不同文章遇到同名用下一個空號碼。標明作者、讀取範圍，只有片段就記「部分保存，全文待補」。存完實際讀回，告訴我實際檔名，並更新索引和「課程進度.md」的02-B：AI讀回和本人核對分開記，舊列不動。
【指令結束】

有不對：說哪裡不同，請它重讀，先不存。
打開AI說的檔案，看得到原文和網址，再回AI：「我已打開檔案核對，02-B本人核對改成已核對」。

========== 選修訊息，只發給需要的人 ==========

【第2課・選修】自己的文章要登入才看得到

主課不需要這段。密碼和驗證碼自己輸入，不貼給AI。
內建瀏覽器沒有你平常 Chrome 的登入，要用平常的 Chrome，才裝官方擴充功能：

Codex：桌面程式 Settings（設定）→ Computer Use → 選 Chrome → 按 Install 到官方商店安裝 → 回設定看到 Manage。回工作室開新對話，輸入 @ 選 Chrome（選剛裝好的那個 Chrome 使用者），再貼第1則的指令。
官方說明：https://learn.chatgpt.com/docs/chrome-extension

Claude Code：照官方頁到 Chrome 商店安裝 Claude in Chrome，用同一個 Claude 帳號登入。桌面程式左下個人圖示 → Settings → Customize → Connectors → Claude in Chrome → Configure。回選好工作室的 Code 本機對話，開啟這個連接再貼第1則的指令。Chrome 側邊欄或 Cowork 也能聊天，但那裡不是你的工作室，存檔要回 Code 本機對話。
官方說明：https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome

看不到這些選項或被公司設定擋住：不改設定，今天先用公開文章或共同文章完成，回群組「登入文章卡住」，之後再補。
