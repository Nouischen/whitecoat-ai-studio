# 第二課｜三天 LINE 帶做

主持人每次複製一個文字框，貼到群組。第一天 3A、3B 是兩條工具路線，學員只做其中一條。

[學員教材入口](https://github.com/Nouischen/whitecoat-ai-studio/blob/v1.1.0/lessons/02-browser/README.md) · [共同練習起始頁](https://github.com/Nouischen/whitecoat-ai-studio/blob/v1.1.0/lessons/02-browser/START.md)

## 第1天

```text
【第2課・第1天｜1／5】今天做什麼

這一課練一件事：讓AI自己打開網頁、讀對原文，存成下次找得到的資料卡。

三天各帶走一樣：
第1天　共同文章的資料卡
第2天　自己文章的資料卡
第3天　新對話自己找回它，並由你決定哪些寫法像你

沿用第一課的「我的AI工作室」，舊資料都保留。用你第一課那一套（Codex 或 Claude Code）就好，不用兩套都裝。
第一課沒做完也能跟，只要工作室在。還沒有工作室，先照第一課做到「準備工作室」成功，再回這裡：
https://github.com/Nouischen/whitecoat-ai-studio/blob/v1.0.1/line/day1.txt
今天的文章是公開的，不需要 GitHub 帳號，也不用裝擴充功能。
```

```text
【第2課・第1天｜2／5】讓AI把教材放好

照第一課的方式，選「我的AI工作室」開一個新對話（Claude Code 用 Code 的本機對話）。整段貼上：

【貼給AI】
請確認目前選的是「我的AI工作室」，先讀「課程規則.md」和「課程進度.md」。
用你的工具讀取下面網址，照裡面的說明放好第二課教材；只新增缺少的檔案，舊檔一律保留：
https://raw.githubusercontent.com/Nouischen/whitecoat-ai-studio/v1.1.0/lessons/02-browser/BOOTSTRAP.md
完成後實際讀回，列出放好的檔案。讀不到就說卡在哪，不要自己編教材。能做的你直接做，要我按的一次只說一步。先不要開始瀏覽器練習。
【指令結束】

應該看到：AI說教材放在「工作模板／02-瀏覽器教材」，並列出檔名。
卡住了：回AI「請改用你的瀏覽器工具打開這個網址讀內容，再照做」。還是不行，回群組「教材下載卡住」，附上AI說的那句話。
提醒：教材下載好，不等於瀏覽器練習完成。
```

```text
【第2課・第1天｜3A／5】用 Codex 的人（用 Claude Code 跳到 3B）

在同一個對話的輸入框打半形「@」，從選單點「Browser」。也可以直接跟AI說「請用內建瀏覽器」。
應該看到：輸入框出現 Browser 標記。用自然語言的人直接貼第4則，下一步要親眼看它點進文章。
找不到：回AI「這個對話有沒有內建瀏覽器工具？沒有就直說，不要用搜尋摘要代替」。還是沒有，回群組「A找不到Browser」，不用研究設定。
```

```text
【第2課・第1天｜3B／5】用 Claude Code 的人

在選好工作室的 Code 本機對話，點右上方地球圖示「瀏覽器／Browser」；或 Windows 按 Ctrl＋Shift＋B，Mac 按 ⌘＋Shift＋B。
應該看到：旁邊開出一個瀏覽器畫面。回原本的輸入框貼第4則。
如果跳出網站允許提示，看清楚這一步要開的是 github.com，再選這次允許。
找不到或顯示已停用：不要改設定，回群組「B找不到Browser」。先留在 Code，不用改去網頁版聊天。
```

```text
【第2課・第1天｜4／5】共同練習：點進文章、對原文

【貼給AI】
請讀「工作模板/02-瀏覽器教材/TASKS.md」的第一天說明，用真正的瀏覽器做：
1. 打開 https://github.com/Nouischen/whitecoat-ai-studio/blob/v1.1.0/lessons/02-browser/START.md
2. 在頁面上點「開始閱讀練習文章」
3. 回報點進去後的實際網址、標題、作者、正文第一句、最後一句，以及讀到全文或部分。網頁選單等雜訊不算正文。
讀完前不要打開教材裡的答案檔。沒有瀏覽器或點不了，就說這步未完成，在進度02-A記下卡點，不要拿下載檔或搜尋摘要代替。先等我核對，不要存檔。
【指令結束】

應該看到：網址結尾是 practice-article.md，標題「讀書會前，我先把問題寫下來」。
你自己核對：用手機或電腦打開上面同一個網址，點「開始閱讀練習文章」，看第一句和最後一句是不是跟AI講的一樣。
AI沒點進去、只講下載檔內容：回它「請在瀏覽器實際點連結，做不到就記未完成」。
```

```text
【第2課・第1天｜5／5】存檔，帶走今天的成果

兩句都對，就貼：

【貼給AI】
我已親自核對第一句和最後一句，正確。請依 TASKS.md 的資料卡範本及同名處理規則，存到「作品」，首選「02-共同練習資料卡.md」，標明「課程共同示範」。存完實際讀回，在「課程進度.md」新增或更新02-A，AI讀回與本人核對分開寫；第一課的舊列不要動。
【指令結束】

有一句不對：告訴AI哪句不同，請它重讀，先不存。

打開「我的AI工作室 → 作品」裡 AI 回報的那張卡，看原文與網址是否都在。正確就回 AI：「我已打開資料卡核對正確，請更新 02-A。」

回群組：
【第2課・第1天】完成／卡在第幾則
工具：Codex／Claude Code
```

## 第2天

```text
【第2課・第2天｜1／2】換成你自己的文章

今天帶走一張文章資料卡，下次要寫衛教文時，可以回來找到原文與網址。

挑一篇公開、你自己點開就看得到全文的文章，部落格、官網、公開貼文都可以，先一篇就好。
選一篇適合交給 AI 的文章，略過含可辨識病人資訊的內容。先分清楚作者：
・本人親自寫
・他人寫或代筆（就算掛你的名字）
代筆的可以存，但之後不拿來當你的語氣。
沒有文章：今天沿用共同文章練，進度記「本人文章待補」，不算本人項目完成。

沿用共同文章的人，直接回 AI：「請讀「工作模板/02-瀏覽器教材/TASKS.md」，沿昨天的共同卡練習；02-B 記本人文章待補。我今天不用另存一篇。」接著跳到今天的群組回報。

有新文章的人回同一個工作室的對話，瀏覽器保持開著（Codex 記得 @ 選 Browser）。把中括號換成你的資料再貼：

【貼給AI】
請讀「工作模板/02-瀏覽器教材/TASKS.md」的第二天說明與它指定的資料卡範本，用瀏覽器讀這篇文章：
網址：［貼完整網址］
作者：［本人親寫／他人或代筆，寫是誰］
用途：［例如診所官網衛教，寫給病人］
原文照實保留，摘要另外放；只讀到一部分就標「部分」，不要補寫。頁面沒寫作者或日期就寫「未標」。先列標題、正文第一句、最後一句和沒讀到的地方；只讀到片段就標「片段末句」。等我核對再存。只讀這一篇，不發文、不傳訊。
【指令結束】

應該看到：AI貼出標題和首尾句，並說全文或部分。
要登入才看得到：先換一篇公開文章，或看今天最後的選修訊息。
```

```text
【第2課・第2天｜2／2】你核對兩處，才存檔

自己打開原文，把首句和末句與 AI 列的兩句逐字比對。都對就貼：

【貼給AI】
我已核對［寫你比的兩處］，正確。請依 TASKS.md 保存。本人親寫放「風格參考/02-網頁文章-01.md」，他人或代筆放「作品/02-他人文章練習-01.md」並記本人文章待補。同一篇重送用原卡，不同文章遇到同名用下一個空號碼。標明作者、讀取範圍，只有片段就記「部分保存，全文待補」。存完實際讀回，告訴我實際檔名，並更新索引和「課程進度.md」的02-B：AI讀回和本人核對分開記，舊列不動。
【指令結束】

有不對：說哪裡不同，請它重讀，先不存。
打開AI說的檔案，看得到原文和網址，再回AI：「我已打開檔案核對，02-B本人核對改成已核對」。


回群組：
【第2課・第2天】已存檔／卡在第幾則
材料：本人親寫／他人或代筆／共同練習
範圍：全文／部分
```

```text
【第2課・選修】自己的文章要登入才看得到

主課不需要這段。密碼和驗證碼自己輸入，不貼給AI。
內建瀏覽器沒有你平常 Chrome 的登入，要用平常的 Chrome，才裝官方擴充功能：

Codex：桌面程式 Settings（設定）→ Computer Use → 選 Chrome → 按 Install 到官方商店安裝 → 回設定看到 Manage。回工作室開新對話，輸入 @ 選 Chrome（選剛裝好的那個 Chrome 使用者），再貼第1則的指令。
官方說明：https://learn.chatgpt.com/docs/chrome-extension

Claude Code：照官方頁到 Chrome 商店安裝 Claude in Chrome，用同一個 Claude 帳號登入。桌面程式左下個人圖示 → Settings → Customize → Connectors → Claude in Chrome → Configure。回選好工作室的 Code 本機對話，開啟這個連接再貼第1則的指令。Chrome 側邊欄或 Cowork 也能聊天，但那裡不是你的工作室，存檔要回 Code 本機對話。
官方說明：https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome

看不到這些選項或被公司設定擋住：不改設定，今天先用公開文章或共同文章完成，回群組「登入文章卡住」，之後再補。
```

## 第3天

```text
【第2課・第3天｜1／2】新對話，自己找回文章

今天帶走：AI在全新對話裡從工作室找回你的文章；哪些寫法像你，由你決定。

從同一個「我的AI工作室」開一個新對話，不要接昨天那個，也不用重貼文章。整段貼：

【貼給AI】
這是新對話。請讀工作室的「開始這裡.md」「課程規則.md」「課程進度.md」和「工作模板/02-瀏覽器教材/TASKS.md」的第三天說明，從索引和進度找到第二課存的資料卡，不要猜檔名。
請告訴我實際檔名、文章標題、作者類型、網址，再從檔案引兩句原文。接著給最多三點初步寫法觀察，每點附原文短句；一篇不夠就直說，不用湊。共同示範、他人或代筆的文章只當練習，不拿來推測我的語氣。先不要存成我的偏好。
【指令結束】

應該看到：AI說出昨天存的檔名，引的兩句和原文一字不差。
找不到：回AI「請沿進度和索引查缺哪個檔，給我最短補法，不要全部重來」。
```

```text
【第2課・第3天｜2／2】你決定，AI才存

先打開AI說的檔案，確認那兩句真的在裡面。
AI的觀察不用全收。例如它說「你喜歡先講故事」，但只有這篇這樣，就可以不採用。

本人親寫的文章，貼：

【貼給AI】
引用我已核對正確。觀察我保留［編號］，修改成［你的說法］，其他不採用。請把我核准的觀察、原文依據和適用場合，備份後合併進第一課的「風格參考/風格觀察.md」。如果第一課尚未建這份檔，先把裁決留在資料卡。全部不採用也可以完成今天的讀回。存完實際讀回給我看，更新「課程進度.md」的02-C：AI讀回已做、本人核對等我確認，舊列不動。
【指令結束】

打開改過的檔案看一眼，再回AI：「我已核對，02-C本人核對改成已核對」。

共同文章、他人或代筆的文章，改貼：

【貼給AI】
引用我已核對正確。這篇不是我親寫，觀察只留在資料卡，不加入我的風格。請依目前材料更新02-C，實際讀回後記錄結果。本人文章項目留待補，待我打開檔案核對後再記本人核對完成。
【指令結束】

回群組：
【第2課・第3天】新對話找回成功／卡在第幾則
我保留或否決的一點：

做到這裡，工作室多了一篇有來源、核對過、新對話也找得到的文章。下一課寫衛教文和電子報，就從這裡接著用。
```
